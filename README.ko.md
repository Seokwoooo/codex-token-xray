# codex-token-xray

내 Codex 세션에서 컨텍스트가 어디에 쓰였는지 보여주고 줄일 수 있는 것만 줄여주는 스킬입니다.

## 설치

```bash
npx skills add Seokwoooo/codex-token-xray
```

Codex 입력창에 이것만 치면 됩니다.

```text
$codex-token-xray
```

모든 프로젝트에서 쓰려면 `-g`를 붙여서 설치합니다. Python 3.9 이상이면 됩니다.

## 실행하면 이렇게 보입니다

![Codex 세션 하나가 컨텍스트를 쓰는 곳](docs/where-tokens-go-ko.svg)

한 컴퓨터의 실제 세션 12개를 읽은 결과입니다.

- 세션은 시작만 해도 약 33,000토큰을 씁니다. Codex 앱 지침 12,000과 기본 지침 5,000과 스킬 목록 6,000이 그 안에 있습니다. 이건 사용자가 줄일 수 없는 부분입니다.
- 작업 중에는 도구가 돌려준 결과가 절반을 넘습니다. 파일을 통째로 읽을 때마다 그대로 쌓입니다.
- 스킬 설명은 세션당 39토큰입니다. 그런데 그 스킬의 본문은 19번 읽히면서 36,000토큰을 썼습니다. 줄여서 효과가 나는 건 본문입니다.

## 줄여주는 것

- 긴 스킬 설명
- 자주 읽히는 긴 스킬 본문. 매번 필요한 것만 남기고 나머지는 `references` 파일로 옮깁니다. 지우는 건 없습니다.
- 프로젝트의 AGENTS.md

바꾸기 전에 diff를 보여주고 승인을 받습니다. zip 백업을 만들고 언제든 되돌립니다.
Playwright 같은 설치 스킬도 대상입니다. 다시 설치하면 덮어써지니 백업이 원본을 갖고 있습니다.

## 건드리지 않는 것

- Codex 기본 스킬과 플러그인. computer-use나 sites 같은 것들.
- 모델과 승인과 샌드박스와 MCP 설정.

## 숫자를 믿어도 되나

- 토큰 합계는 Codex가 남긴 사용량 기록 그대로입니다.
- 항목별 나누기는 크기로 추정합니다. 실측과 비교하면 0.85 수준으로 맞았고 보고서에 그 비율이 같이 찍힙니다.
- 줄인 효과는 그 뒤에 시작한 세션부터 보입니다.
